## Which few I’d keep

For a small **no-cost/open-weight** shortlist, I’d keep **Atria Dawn Preview** and **Qwen3-Coder-Next**; their published weights are MIT-licensed and Apache-2.0 respectively. That means the weights are available to run yourself; it doesn’t guarantee a free hosted API quota. [Atria repository](https://github.com/atria-asi/Atria-Dawn), [Qwen model card](https://huggingface.co/Qwen/Qwen3-Coder-Next)

I’d add **Agnes 3.0 Pro** only if your provider confirms its exact model identity and free quota. Its Tasks implementation scored well, but I couldn’t verify that exact model listing publicly. GPT-5.4 Nano’s API is priced per token, and Upstage lists Solar Pro 3 as paid and scheduled to end service on **October 30, 2026**, so I wouldn’t count either as a free API option. [OpenAI model pricing](https://developers.openai.com/api/docs/models/gpt-5.4-nano), [Upstage pricing and service notice](https://www.upstage.ai/pricing/api)

Before the next round, the plan needs a status cleanup: it marks Checklist Items done despite no module files, its current-scope summary conflicts with the completed rows, and the Checklists and Labels model attributions disagree. For a fair comparison, give the shortlisted models the **same module, starting snapshot, prompt, and tools**.
